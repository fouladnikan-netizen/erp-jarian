## Notes (not extra tables)

- **Independent root causes: 8.** RC1+RC2+RC3 reconstruct **120 FAIL**. RC4 (19 Type WARNING) + RC5 (38) + RC6 (~33) reconstruct **71 WARNING**. RC7 is by-design, not a ninth FAIL bucket. RC8 is why the CSV could not be replayed from git.
- **False positives to drop before any heal:** RC1 (DDL-51 applied to تسمه فولادی), RC5 («تست» in لوله تست آب/گاز).
- **Proven attribute replacements (only):** fittings display → bound `fitting_material`; bed rebar display/identity → bound `bed_width` (`attr_mtt5gf7kflpbbd`) instead of `width`. **Not proven:** any substitute for unbound `grade` on `ورق روغنی` — remove the token.
- **kind on میلگرد بستر:** `valueScope=PRODUCT`, required, `isIdentityRelevant=true`. Required change to add it to identity: **none**.
- **strip_width TRANSACTION→PRODUCT effect on the 105:** identity gains a second participant; SKU gains a fifth hyphen segment; 105 distinct Products remain valid; issued SKUs already contain width; no migration if DDL-57 is kept.
